## 🚀 Node Installation

Run the following commands as root on your clean VPS node to join it to your AI cluster:

    # 1. Update package lists
    apt update && apt upgrade -y

    # 2. Download the core installer
    wget -qO install.sh https://raw.githubusercontent.com/Edutechz0/autoscript/main/install.sh

    # 3. Make executable and run
    chmod +x install.sh
    ./install.sh

### Installation Prompts
During setup, you will be authenticated against the MongoDB Atlas cluster. You will need:
1. **VPS HWID** (Generated locally and authorized in your bot).
2. **Main Domain:** (e.g., `vpn.yourdomain.com`).
3. **Nameserver Domain:** (e.g., `ns.yourdomain.com` for SlowDNS).
